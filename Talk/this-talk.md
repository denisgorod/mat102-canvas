There were no slides.

This talk is an inquiry map — nine nodes, eight questions on the edges, the same viewer as the
course, the same repository, the same pull-request pipeline. Every transition you sat through was
an edge, and at one point **you** chose which one we took.

>[!idea]
If the method can carry a talk about itself, it can carry your course.

And it has the same button as every other node:

>[!question] Ask a question about this node
Whatever you were going to ask in the Q&A — put it in the map instead. It'll be an issue before
you leave the room, and I'll answer it where the next person will find it.
