>[!d] Definition
> A **proposition** is a statement with a definite **truth value**: it is either true (T) or false (F), never both and never neither. The value need not be known: Goldbach's conjecture, that every even integer greater than $2$ is a sum of two primes, is a proposition, though its truth value is unknown.

>[!info] Note
> A proposition need not be true, only unambiguously true or false. The word "proposition" also names a proven result; context decides which is meant.

>[!e] Worked example
> "$2 + 2 = 5$" is a false proposition. "For all real $x, y$, if $x < y$ then $x^2 < y^2$" is a false proposition: $x = -2$, $y = 1$ give $x < y$ but $x^2 = 4 > 1 = y^2$. A question, such as "Is $7$ prime?", is not a proposition.
