>[!d] Definition
> A **mathematical definition** states the entire meaning of a term: an object has the defined property **exactly when** it satisfies the stated condition. Though written with "if", a definition is read as "if and only if". Any condition proved logically equivalent to it may be used in its place.

>[!e] Worked example
> An integer $n$ is **even** if $n = 2m$ for some $m \in \mathbb{Z}$. Then $0$ is even, since $0 = 2 \cdot 0$. That the even integers are exactly those with last decimal digit $0, 2, 4, 6$ or $8$ is a theorem tied to base $10$ (in base $3$ the even number $4$ is written $11$), not the definition.

>[!warning] Common error
> Settling an edge case such as $0$ by what the word suggests instead of checking the condition.
